# Zutaten

Zutaten können aus [[Pflanzen]] oder [[Kreaturen]] gewonnen werden. Sie werden auf zwei verschiedene Arten unterschieden: Effektweise und Häufigkeit. Die Effektweise bestimmt, ob eine Zutat einen externen oder internen Effekt oder beides hat. Die Häufigkeit gibt an, wie häufig diese Zutat vorkommt. Zutaten haben außerdem eine [[Effektarten|Effektart]].

## Effektweise von Zutaten

Zutaten können einen externen oder internen Effekt oder beides davon haben. Dies bezeichnet man als die Effektweise. Zutaten mit externen Effekten können für die Zubereitung von [[Zubereitung#Pasten|Pasten]] verwendet werden. Jene mit internen Effekten kommen bei der Kreation von [[Zubereitung#Tränke|Tränken]] zum Einsatz. Zutaten, welche sowohl einen externen als auch einen internen Effekt haben, können für beide Zubereitungsformen verwendet werden.

## Häufigkeit von Zutaten

Die Häufigkeit einer Zutat gibt an, wie oft sie auf Parlea vorkommt. Dies ergibt sich logischerweise aus der Häufigkeit der Zutatenquelle, also wie oft die [[Kreaturen|Kreatur]] oder die [[Pflanzen|Pflanze]], aus welcher die Zutat gewonnen wird, vorkommt.
Gleichzeitig hat die Häufigkeit einer Zutat aber auch Einfluss darauf, wie intensiv ihr Effekt ist. Davon ausgenommen sind Zutaten, welche statische Effekte verursachen. Für alle anderen ergibt sich der Effekt der Zutat aus ihrer Häufigkeit, basierend auf folgender Tabelle:

| Häufigkeit | Effektwürfel                    |
| ---------- | ------------------------------- |
| häufig     | [[Würfelwürfe#Würfelübersicht\|W4]]  |
| gewöhnlich | [[Würfelwürfe#Würfelübersicht\|W4]]+3  |
| selten     | [[Würfelwürfe#Würfelübersicht\|W4]]+5 |

## Verwendung von rohen Zutaten

Ist nicht die Zeit für die [[Zubereitung]] von Tränken oder Salben gegeben, fehlen dafür benötigte [[Zubereitungsgegenstände]] oder verfügen [[Charaktere]] nicht über die [[Fertigkeiten|Fertigkeit]] [[Alchemie]], so können Zutaten auch in rohem Zustand verwendet werden. Sie wirken mit ihrem [[#Häufigkeit von Zutaten|Häufigkeitswürfel]].
