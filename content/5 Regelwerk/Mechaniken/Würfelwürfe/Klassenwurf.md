# Klassenwurf

Klassenwürfe kommen bei verschiedenen Aktionen und Szenarien zum Einsatz. Hierzu gehören die [[Klassen#Klassentätigkeit|Klassentätigkeit]], bestimmte [[Fähigkeiten]],   das Erhöhen von [[Lebenspunkte|Lebens-]] und [[Magiepunkte|Magiepunkten]] beim [[Klassenstufen#Stufenaufstieg|Stufenaufstieg]] und die Rückerstattung von [[Magiepunkte|Magiepunkten]] bei [[Zaubermanöver#Rückerstattung von Magiepunkten|kritischen Zaubern]].
In all diesen Fällen wird ein meist unmodifizierter **Wurf mit dem Stufenwürfel** durchgeführt.

## Stufenwürfel

Jede [[Stufe]] hat einen [[Würfelwürfe#Die Würfel|Würfel]], welcher ihr zugewiesen ist. Dies nennt man den Stufenwürfel. Der Stufenwürfel jeder Stufe ergibt sich aus folgender Tabelle. **[[Würfelwürfe#Überwürfe|Überwürfe]] sind hierbei möglich.**

| [[Klassenstufen\|Stufe]] | Stufenwürfel                 |
| ------------------------ | -------------------------------- |

| [[Lehrling]]             | [[Würfelwürfe#Die Würfel\|W6]]  |
| [[Geselle]]              | [[Würfelwürfe#Die Würfel\|W8]] |
| [[Meister]]              | [[Würfelwürfe#Die Würfel\|W10]] |
| [[Koryphäe]]             | [[Würfelwürfe#Die Würfel\|W12]]|
