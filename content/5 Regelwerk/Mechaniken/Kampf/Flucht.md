# Flucht

Scheint ein Kampf aussichtslos, so kann versucht werden, aus diesem zu fliehen. Hierfür muss eine [[vorteilhaft und unvorteilhaft#unvorteilhaft|unvorteilhafte]] Probe auf die [[Fertigkeiten|Fertigkeit]] [[Athletik]] geworfen werden, die **größer** als **der höchste [[Bewegung|Bewegungswert]] unter den Gegnern** ist.
Gelingt diese, haben alle Gegner trotzdem noch eine Chance auf einen Angriff, allerdings ist dieser nur als [[Waffen im Kampf#Fernkampf|Fernkampf]] möglich.
Schlägt die Probe fehl, haben Gegner die Möglichkeit, einen [[vorteilhaft und unvorteilhaft#vorteilhaft|vorteilhaften]] [[Angriffsmanöver|Angriff]] durchzuführen.
So oder so ist der Kampf mit Antritt der Flucht beendet. Die Gegner können allerdings die Verfolgung aufnehmen und so einen neuen Kampf einleiten.
