# Zubereitung

Das Anfertigen von Tränken und Salben aus [[Zutaten]] versteht man als Zubereitung. Die Zutaten können dabei entweder direkt  vermischt werden oder auf verschieden Weisen vorbereitet werden. Hierbei kommen verschiedene [[Zubereitungsgegenstände]] zum Einsatz. Die Menge an Vorbereitungsschritten hat Einfluss auf die Qualität des Endprodukts.

## Auswahl der Zutaten

Soll eine Zubereitung angefertigt werden, muss man sich zuerst entscheiden, welchen Effekt (bzw. im Fall einer [[Zubereitung#Essenz|Essenz]] Effekte) die Kreation haben soll. Es können **maximal 5 Zutaten** verwendet werden, welche den gewünschten Effekt haben. Die Verwendung mehrerer Zutaten erleichtert die Zubereitung um 1 pro Zutat nach der Ersten. Hat die Zubereitung negative Effekte, ist also ein Gift, entfällt der [[Zutaten#Häufigkeit von Zutaten|Häufigkeitsbonus]] der Zutaten und der Schaden reduziert sich um 1 pro zusätzlich verwendeter Zutat.

## Vorbereitungsweisen

[[Zutaten]] können auf verschiedene Weisen vorbereitet werden, bevor sie verwendet werden können. Welche Vorbereitungsweise zum Einsatz kommt, geht von der Zutat aus. Die Vorbereitung erfordert einen eigenen [[Würfelwürfe|Würfelwurf]].

### Stampfen

Das Zerstampfen von [[Zutaten]] geschieht mit Hilfe von [[Mörser und Stößel]].

### Rösten

Zutaten können mit Hilfe einer [[Röstschale]] geröstet werden. Eine Feuerquelle ist hierfür vonnöten.

### Destillieren

[[Retorte|Retorten]] kommen beim Destillieren von Zutaten zum Einsatz. Hierfür ist eine Feuerquelle nötig.

## Zubereitungsformen

Welche Form eine Zubereitung annimmt, geht von der Mischweise aus. Werden die Zutaten in einer Schale oder Schüssel mit Fett vermengt, spricht man von einer Paste. Werden sie stattdessen in einem [[Braukessel]] mit Alkohol gemischt, resultiert dies in einem Trank.

### Pasten

Pasten sind Zubereitungen aus einer oder mehreren [[Zutaten]], welche mit einem Fett vermischt werden. Hierfür können Pflanzenfette oder tierische Fette wie Schmalz oder Butter verwendet werden. Sie werden meist in Schüsseln oder Schalen zubereitet, können in Notfällen aber auch per Hand vermengt werden. Pasten übernehmen den externen Effekt der [[Zutaten#Effektweise von Zutaten|Zutat]]. Pasten können **maximal einen Effekt** haben. Pasten können zwei Qualitätsstufen haben, Salbe und Balsam.

#### Salben

Werden Pasten aus unpräparierten [[Zutaten]] zubereitet, spricht man von einer Salbe. Die Zubereitung von Salben hat eine Grundschwierigkeit von 8.
Eine Salbe **verdoppelt** den Effekt der [[Zutaten|rohen Zutat]]. Dies **inkludiert den [[Zutaten#Häufigkeit von Zutaten|Zutatenbonus]]**. Eine Salbe auf Basis einer gewöhnlichen Zutat hat also einen Effekt von 2[[Würfelwürfe#Würfelübersicht|W4]]+6.

#### Balsam

Werden die Zutaten vor dem Vermengen gestampft, geröstet oder destilliert, bezeichnet man das Resultat als einen Balsam. Die Zubereitung eines Balsams **verdoppelt die Effektdauer** und fügen einen Würfel zum Trankeffekt hinzu. Die Zubereitung von Balsam hat eine Grundschwierigkeit von 12.

### Tränke

Tränke sind Zubereitungen aus einer oder mehreren [[Zutaten]], welche in einer alkoholischen Flüssigkeit wie Schnaps oder Weinbrand aufgekocht werden. Die Zubereitung von Tränken erfolgt in einem [[Braukessel]] und erfordert logischerweise eine Feuerquelle. Tränke übernehmen den internen Effekt der [[Zutaten#Effektweise von Zutaten|Zutat]]. Tränke haben vier verschiedene Qualitätsstufen, wovon die ersten drei nur einen Effekt und die vierte und höchste maximal zwei Effekte haben kann.

#### Sud

Wenn [[Zutaten]] ohne Vorbereitungsschritte zu Tränken gebraut werden, spricht man von einem Sud. Diese Zubereitung hat eine Grundschwierigkeit von 10. Ein Sud **verdoppelt** den [[Zutaten#Häufigkeit von Zutaten|Häufigkeitsbonus]] und **verdreifacht** die verwendeten Würfel. Ein Sud auf Basis einer gewöhnlichen Zutat resultiert also in einem Effekt von 3[[Würfelwürfe#Würfelübersicht|W4]]+6.

#### Tinktur

Durchlaufen die [[Zutaten]] vor dem Trankbrauen einen Vorbereitungsschritt, werden also entweder gestampft, geröstet oder destilliert, bezeichnet man das Resultat als Tinktur. Tinkturen  verwenden **ein Würfel mehr als ein Sud** . Hat eine Zutat also einen Effekt mit 1W4, werden, statt wie beim Sud 3[[Würfelwürfe#Würfelübersicht|W4]], 4W4 geworfen. Tinkturen haben bei ihrer Zubereitung eine Grundschwierigkeit von 14.

#### Essenz

Werden [[Zutaten]] auf zwei Arten vorbereitet und anschließend zu einem Trank gebraut, spricht man von einer Essenz. Essenzen haben **eine verdoppelte Effektdauer** und fügen im Vergleich zur Tinktur einen [[Würfelwürfe#Würfelübersicht|W4]] hinzu. Eine Essenz aus einer [[Zutaten#Häufigkeit von Zutaten|seltenen Zutat]] resultiert also in folgendem Effekt: 5W4+10. Ihre Zubereitung hat eine Grundschwierigkeit von 16.

#### Elixier

Elixier nennt man einen Trank, bei dem [[Zutaten]] verwendet werden, welche davor auf drei Weisen vorbereitet, also zerstampft, geröstet und destilliert, wurden. Elixiere  können **einen zweiten Effekt** haben. Dieser zweite Effekt ist allerdings abgeschwächt, und verdoppelt lediglich die Basiswirkung der Zutat. Die Hauptzutat in einem Elixir verwendet einen [[Würfelwürfe#Würfelübersicht|W4]] mehr als eine Essenz. Wird also ein Elixir gebraut, welches auf Basis gewöhnlicher Zutaten [[Lebenspunkte]] wiederherstellt und als sekundären Effekt auf Basis häufiger Zutaten [[Magiepunkte]] wiederherstellt, hat dieses Elixir einen Effekt von 6W4+6 LP und 2W4 MP. Ihre Zubereitung hat eine Grundschwierigkeit von 20.
