# Klassenstufen

Neben dem [[Level]] von [[Charaktere|Charakteren]] drückt auch die Klassenstufe, oft nur als Stufe bezeichnet, die Erfahrung eines Charakters aus. Dabei bezieht sie sich insbesondere auf die Erfahrung innerhalb der [[Klassen|Klasse]] bzw. des [[Pfade|Pfads]] und bringt daher auch stets neue [[Fähigkeiten]] bzw. Fortschritte innerhalb dieser mit sich.
Charaktere erreichen mit bestimmten Leveln auch eine neue Klassenstufe. Es gibt folgende Klassenstufen:

| Charakterlevel | Klassenstufe |
| -------------- | ------------ |
| 1-2            | [[Novize]]   |
| 3-5            | [[Lehrling]] |
| 6-9            | [[Geselle]]  |
| 10-14          | [[Meister]]  |
| 15+            | [[Koryphäe]]             |

## Stufenaufstieg

Erreichen [[Charaktere]] eine neue Klassenstufe, erhalten sie nicht nur oft neue/verbesserte [[Fähigkeiten]].  Sie erhalten auch einen zusätzlichen Bonus auf ihre [[Lebenspunkte|Lebens-]] und [[Magiepunkte]].  Dieser dauerhafte Bonus ergibt sich aus einem unmodifizierten [[Klassenwurf]].

Beim Erreichen einer neuen Stufe erhöht sich außerdem die [[Aufmerksamkeit]] automatisch um 1.

### Zusätzliche [[Level#Fertigkeitssteigerung|Fertigkeitspunkte]]

Beim Erreichen einer neuen Klassenstufe stehen, statt wie üblich 10, **12 Fertigkeitspunkte** zur Verfügung.

### Start als [[Novize]]

Charaktere starten bei Level 1 als [[Novize|Novizen]]. Als solche gelten sie als [[niedere Kreaturen]].

### Aufstieg zum [[Lehrling]]

Beim Erreichen der Stufe [[Lehrling]] wählen [[Charaktere]] ihren [[Pfade|Pfad]] innerhalb ihrer [[Klassen|Klasse]]. Dieser gewährt ihnen verbesserte [[Attribute#Steigerung durch Pfad|Attribute]] und neue [[Fähigkeiten]].  Ab diese Stufe werden Charaktere als [[gewöhnliche Kreaturen]] angesehen.

### Aufstieg zum [[Geselle|Gesellen]]

Ab Erreichen der Stufe [[Geselle]], können [[Charaktere]] ihre [[Attribute#Erhöhung ab der Gesellenstufe|Attribute verbessern]].  Sie können während einer [[Kampfrunde]] außerdem ihre gesamte [[Bewegung]] opfern, um ein [[Zusatzmanöver]] durchzuführen.

### Aufstieg zum [[Meister]]

[[Meister]] können ein [[Zusatzmanöver]] in einer [[Kampfrunde]] ausführen, ohne dafür ihre [[Bewegung]] opfern zu müssen. Sie werden von nun an als [[höhere Kreaturen]] betrachtet.

### Aufstieg zur [[Koryphäe]]

[[Koryphäe|Koryphäen]] können zwei [[Manöver]] während einer [[Kampfrunde]] ausführen, unabhängig davon um welche Manöverart es sich handelt. Koryphäen gelten als [[epische Kreaturen]].
