# Bewegung

Der [[Charakterwerte|Charakterwert]] Bewegung drückt aus, wie weit sich ein [[Charaktere|Charakter]] in einer [[Kampfrunde]] maximal bewegen kann. Sie bestimmt außerdem, wie viele Kilometer ein Charakter sich bewegen kann, bevor eine [[Rasten|Rast]] nötig ist.  Der Bewegungsradius wird prinzipiell in Metern (für den Kampf) ausgedrückt und basiert auf der [[Agilität]] des Charakters. Standardmäßig ist es **der Agilitätswert des Charakters**, also eine Zahl von 1 bis 20, **mindestens aber 5**, der Bewegungsradius des Charakters in Metern. Dieser Wert kann allerdings noch weiter modifiziert werden, sei es durch spezielle [[Eigenschaften|Charaktereigenschaften]], [[Zaubersprüche]], [[Ausrüstung]] oder Umstände im Kampf.\
Bewegung wird außerdem noch durch getragene [[Ausstattung]] beeinflusst. Der Bewegungswert wird um den **doppelten [[Ausstattung#Ausstattungsmalus|Ausstattungsmalus]]** der Ausstattung reduziert.

## Bewegung zum Reisen

[[Charaktere]] können sich ihren Bewegungswert bewegen, bevor sie eine [[Rasten|Rast]] einlegen müssen. Hierbei kann es sich einmal auch um eine [[Rasten#kurze Rast|kurze Rast]] handeln, bevor eine [[Rasten#lange Rast|lange Rast]] eingelegt werden muss. Somit ergibt sich pro lange Rast, unter der Annahme einer kurzen Zwischenpause, eine Reisedistanz von dem doppelten Bewegungswert in Kilometern. Faktoren, welche den Bewegungswert beeinflussen, wie [[Zaubersprüche]], [[Eigenschaften]], [[Ausrüstung]] und [[Terrain]], werden beim Reisen gleichermaßen berücksichtigt wie im Kampf.

### Reisen in Gruppen

Reisen mehrere [[Charaktere]] gemeinsam in einer Gruppe, so wir der durchschnittliche Bewegungswert aller beteiligten Gruppenmitglieder herangezogen.

### Reisen mit [[Fortbewegungsmittel]]

Neben der Reise zu Fuß stehen Charakteren auch unterschiedlichste [[Fortbewegungsmittel]] zur Verfügung. Diese ermöglichen es ihnen, größere Distanzen zurückzulegen. Die Fortbewegungsmittel verwenden statt dem doppelten Bewegungswert der Charaktere pro Tag den Reisewert ihres [[Fortbewegungsmittel|Fortbewegungsmittels]].

## Reduktion der Bewegung

Der Bewegungsradius von Charakteren kann unter gewissen Umständen stark eingeschränkt sein. Dies ist bei Bewegung in schwierigem Gelände oder beim Schleichen der Fall.

### Bewegen beim [[Schleichen]]

Wollen sich [[Charaktere]] heimlich fortbewegen, müssen sie dafür etwas langsamer und gemächlicher vorgehen. Aus diesem Grund **reduziert Schleichen die Bewegung um 50 %**.

### Bewegen im schwierigen [[Terrain]]

Bei Bewegung durch schwieriges [[Terrain]] kann dieses den Bewegungsradius teils stark einschränken. Diese Reduktion gilt sowohl für die Bewegung im Kampf als auch für Reisebewegungen über die Karte. Bei letzterem ist allerdings zu beachten, dass der Malus **um 25 % reduziert ist**, wenn auf einer Straße gereist wird. Die genaue Einschränkung ergibt sich aus folgender Tabelle:

| [[Terrain]]   | Malus auf Bewegung |
| ------------- | ------------------ |
| [[Berg]]      | -50 %              |
| [[Grasland]]  | entfällt           |
| [[Hügelland]] | -25 %              |
| [[Sumpf]]     | -50 %              |
| [[Tundra]]    | - 25 %             |
| [[Uferland]]      | - 25 %             |
| [[Wald]]     | - 50 %             |
| [[Wüste]]     | - 25 %                   |
