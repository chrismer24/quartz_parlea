# Aufmerksamkeit

Die Aufmerksamkeit von Charakteren gibt an, ob sie bemerken, wenn Andere [[Manöver]] gegen sie ausführen. Dies bezieht sich insbesondere auf [[Schleichen|Schleich]][[Manöver|manöver]] wie [[Diebstahl|Diebstähle]] und  [[Angriffsmanöver#Schleichangriffe|Schleichangriff]]. Für die Berechnung der Aufmerksamkeit wird entweder der [[Attribute#Attributsboni|Attributsbonus]] von [[Intelligenz]] oder der [[Grundwert]] von [[Wahrnehmung]] zum Aufmerksamkeitsgrundwert addiert. Dieser basiert auf der [[Klassenstufen|Klassenstufe]].

## Ermitteln der Aufmerksamkeit

| Stufe        | Formel                                                                                                            |
| ------------ | ----------------------------------------------------------------------------------------------------------------- |
| [[Novize]]   | 5 + ([[Attribute#Attributsboni\|Attributsbonus]] [[Intelligenz]] **ODER**  [[Grundwert]] [[Wahrnehmung]]) |
| [[Lehrling]] | 6 + ([[Attribute#Attributsboni\|Attributsbonus]] [[Intelligenz]] **ODER**  [[Grundwert]] [[Wahrnehmung]]) |
| [[Geselle]]  | 7 + ([[Attribute#Attributsboni\|Attributsbonus]] [[Intelligenz]] **ODER**  [[Grundwert]] [[Wahrnehmung]]) |
| [[Meister]]  | 8 + ([[Attribute#Attributsboni\|Attributsbonus]] [[Intelligenz]] **ODER**  [[Grundwert]] [[Wahrnehmung]]) |
| [[Koryphäe]]             |9 + ([[Attribute#Attributsboni\|Attributsbonus]] [[Intelligenz]] **ODER**  [[Grundwert]] [[Wahrnehmung]])|
